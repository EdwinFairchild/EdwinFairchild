### Now

Building [BKPT Labs](https://bkptlabs.com): embedded observability and hardware trace.

- [**ViewAlyzer**](https://viewalyzer.net/) records what the runtime actually did (instruction trace, RTT, instrument data) and turns it into flame graphs, timelines, and regression tests you can run in CI.
- **BKPT #1** is the trace probe behind it: one USB 3 cable, an FPGA doing the capture, and a probe you can teach your own tricks.
- **BKPT Studio** is the IDE that puts both in front of a human and an agent at the same time.
